A planned feature is to implement two different types of entities that can be programmed: **Bugs** and **Drones**.

**Bugs** are supposed to be a lower tier programmable entity, which is bound to the ground (and affected by gravity). They should otherwise be fully programmable within the bounds of disk space availability.

**Drones** are supposed to be a higher tier programmable entity, which can fly (and are not affected by gravity). Like the bug, they should be restricted to disk space availability.

Both should have different tiers with increasing upgrade slots (see [[Drone and Bug Upgrades]])

*Undecided:* Should these entities be killable and targeted by hostile mobs? There could be an invulnerability upgrade or something like a "ghost" upgrade to make them invisible to hostile mobs.
