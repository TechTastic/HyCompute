**Module:** `os`


| Entry             | Description                                                    |
| ----------------- | -------------------------------------------------------------- |
| `clock()`         | Returns the elapsed time since the computer started in seconds |
| `time()`          | Returns the current time in seconds since January 1, 1970 UTC  |
| `date()`          | Returns the current date on the server                         |
| `getComputerID()` | Returns the computer's ID                                      |
| `shutdown()`      | Turns off the computer                                         |
| `reboot()`        | Reboots the computer                                           |
